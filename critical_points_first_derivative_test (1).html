Critical Points & the First Derivative Test

Teaching calculus, one derivative at a time
After using this, you should be able to find all critical points of a function and classify each as a local maximum, local minimum, or neither using the First Derivative Test.
01 — Core Concepts

A critical point of a function \(f\) is an \(x\)-value in the domain of \(f\) where something special happens to the derivative — it either equals zero, or it fails to exist. These are the candidates for local extrema.

Definition — Critical Point

A number \(c\) is a critical point of \(f\) if \(c\) is in the domain of \(f\) and either
\[f'(c) = 0 \qquad \text{or} \qquad f'(c) \text{ does not exist.}\]

Finding a critical point tells you where an extremum might be. The First Derivative Test tells you what kind — or whether it's an extremum at all.

The First Derivative Test

Let \(c\) be a critical point of a continuous function \(f\). Examine the sign of \(f'\) on either side of \(c\):

  • If \(f'\) changes from positive → negative, then \(f(c)\) is a local maximum.
  • If \(f'\) changes from negative → positive, then \(f(c)\) is a local minimum.
  • If \(f'\) does not change sign, then \(f(c)\) is neither (a saddle/inflection point).

Why does this work? When \(f' > 0\), the function is increasing. When \(f' < 0\), it is decreasing. A peak occurs when increasing gives way to decreasing; a valley when decreasing gives way to increasing.

Example 1 — Polynomial
1
Find the critical points of \(f(x) = 2x^3 - 9x^2 + 12x - 4\).
Differentiate: \(f'(x) = 6x^2 - 18x + 12\).
2
Set \(f'(x) = 0\):
\(6x^2 - 18x + 12 = 0 \;\Rightarrow\; x^2 - 3x + 2 = 0 \;\Rightarrow\; (x-1)(x-2)=0\)
Critical points: \(x = 1\) and \(x = 2\).

Example 2 — Function with f' undefined
1
Find and classify critical points of \(f(x) = x^{2/3}\).
Differentiate: \(f'(x) = \dfrac{2}{3}x^{-1/3} = \dfrac{2}{3x^{1/3}}\).
2
Is \(f'(x) = 0\)? Set \(\dfrac{2}{3x^{1/3}}=0\) — there is no solution (the numerator is constant 2).
Is \(f'(x)\) undefined? Yes, at \(x = 0\) (division by zero). Since \(0\) is in the domain of \(f\), it is a critical point.
